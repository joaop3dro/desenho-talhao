# desenho-talhao
Aplicação mobile desenvolvida em Delphi FMX para Android e iOS, focada no desenho e gerenciamento de talhões agrícolas diretamente no mapa. O app permite delimitar áreas por meio de polígonos interativos, facilitando o controle territorial, planejamento agrícola e visualização das propriedades rurais em tempo real.

🚜 Funcionalidades Principais

📍 Exibição de mapa interativo (GPS)

✏️ Desenho de talhões diretamente no mapa (polígonos)

🔺 Criação e visualização de áreas delimitadas

📐 Cálculo automático de área do talhão

📱 Compatível com Android e iOS

🧭 Suporte a zoom, pan e navegação no mapa

💾 Persistência dos dados (local ou via integração com API, conforme implementação)

🎨 Interface responsiva construída com FireMonkey (FMX)

🛠️ Tecnologias Utilizadas

Delphi FMX (FireMonkey)

Componentes de mapa (nativos)

Manipulação de coordenadas geográficas (latitude/longitude)

Arquitetura orientada a eventos e objetos

📱 Plataformas Suportadas

✅ Android

✅ iOS
